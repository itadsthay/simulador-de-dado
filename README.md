Um mini jogo em Python onde o jogador tenta adivinhar um número aleatório entre 1 e 6. A cada jogada, o jogador escolhe um número e o programa informa se acertou ou não. 
O jogo continua até que o usuário digite 0 ou forneça uma entrada inválida.

Como executar:
Para rodar o jogo, execute o script em um terminal com Python instalado. 
O programa solicitará que você digite um número entre 1 e 6 ou 0 para sair. 
Ao final, ele mostrará o total de jogadas e acertos.
